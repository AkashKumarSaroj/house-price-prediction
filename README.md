# House Price Prediction

This is my project for the Machine Learning Engineer internship at YuvaIntern. I'm building an ML pipeline that predicts house prices based on stuff like area, number of rooms, year built, and location.

Doing this over 6 weeks as part of the internship, so I'll be pushing updates here week by week as I go through planning, data preprocessing, model building, evaluation, and finally deployment.

## What's the problem?

Basically trying to predict a house's sale price using its features (area, bedrooms, bathrooms, year built, neighborhood etc). It's a classic regression problem, using a public dataset (planning to use the Ames Housing dataset from Kaggle).
